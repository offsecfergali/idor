# Acme Market — Next.js / Vercel

Normal-looking e-commerce/customer portal using only JavaScript/React/Next.js. No Python.

## Local
npm install
npm run dev

Open http://localhost:3000

Demo: alice / alice123

## Vercel
Push to GitHub, import the repository into Vercel, and deploy. Vercel detects Next.js automatically.

The `/api/orders/[id]` endpoint intentionally exposes order objects without an ownership check for controlled security testing. Keep this project private or in an authorized test environment.
